# Task 21 - Date Parsing and Datetime Basics

## Overview
This task demonstrates how to parse, convert, and work with dates using Python and Pandas.

## Topics Covered
- Creating a sample DataFrame
- Converting text dates using pd.to_datetime()
- Checking datetime data types
- Extracting year, month, and day
- Extracting weekday names
- Extracting weekday numbers
- Handling invalid dates using errors="coerce"
- Filtering records by date
- Sorting records by date
- Displaying the final dataset

## Tools Used
- Python
- Pandas
- Jupyter Notebook

## File Included
- task21_date_parsing_datetime_basics.ipynb

## Outcome
Learned how to convert text into datetime values and extract useful date information for data analysis.
